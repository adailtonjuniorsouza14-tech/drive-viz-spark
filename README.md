# Drive Dashboard Pro

Utilizando o conector nativo do Google drive que acabei de ativar, crie um dashboard interno estilo Power BI. Conecte-o à minha planilha dentro da pasta 06 Crie cartões de KPI e gráficos do Recharts que puxam as linhas de todas as abas aba em tempo real. por data  recente Adicione também um botão para atualizar manualmente os dados."
